### 🛠️ Команды

| Команда | Что делает      |
| ------- | --------------- |
| `ls`    | список файлов   |
| `cd`    | перейти в папку |
| `pwd`   | текущий путь    |
| `cat`   | вывести файл    |
| `file`  | тип файла       |
| `find`  | поиск файла     |
