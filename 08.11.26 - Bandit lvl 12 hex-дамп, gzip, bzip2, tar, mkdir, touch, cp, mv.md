### 🎯 Что делал

Сегодня я узнал много нового: например, как создавать, копировать, переименовывать, перемещать и менять расширение у файлов и папок, а также научился читать многократно сжатый разными способами (hex-дамп, `gzip`, `bzip2`, `tar`) текстовый файл. Но обо всём по порядку.

Изначально мне дали многократно сжатый текстовый файл с паролем и порекомендовали создать отдельную папку для работы с ним. Что я и сделал командой `mkdir dnam`, указав ей путь, в какой папке её создать. Полная команда: `mkdir dnam /tmp`. После чего я скопировал сжатый текстовый файл в эту папку командой `cp fnam1 /tmp/dnam` и продолжил работу в этой папке.

Изначально файл был представлен в виде hex-дампа — это можно было понять по характерному выводу содержимого с помощью команды `cat`. Чтобы преобразовать hex-дамп обратно, я использовал команду `xxd -r` и перенёс вывод в новый файл с помощью `>` для дальнейшей работы. Полная команда: `xxd -r fnam1 > fnam2`. После я узнал, каким образом был сжат файл, по команде `file fnam2` — в строку мне вывело `fnam2: gzip compressed data`, что значит, файл был сжат с помощью `gzip`. После чего командой `gzip -d fnam2.gz` я могу обратно разжать файл, но я понял, что команда по умолчанию ищет  расширение `.gz` и без него выдает ошибку я поменял его. Это было сделать несложно командой `mv fnam2 fnam2.gz` — эта команда переименовывает файлы. Сам файл после разжатия потерял своё расширение.

Далее я не буду расписывать все действия, которые я уже писал выше. По итогу файл был сжат с помощью `bzip2`: я снова поменял расширение файла на `.bz2` и разжал файл командой `bzip2 -d fnam2.bz2`. Затем файл был архивирован с помощью `tar`: я опять же поменял файлу расширение на `.tar`. Распаковывал сам файл я с помощью команды `tar -xf fnam2.tar`; флаги означают: `-x` — extract (распаковать), `-f` — указать файл архива. После мне в папку добавился другой файл с расширением `.bin`. Далее я повторял все вышесказанные действия, пока команда `file` не выдала мне `fnam: ASCII text` — уже в нём был нужный мне пароль от следующего уровня.

---
### 🧠 Что понял

- Научился создавать, копировать, переименовывать, перемещать файлы и менять им расширение.
- Понял, как определять, каким образом был сжат файл.
- Некоторые команды могут не работать с файлами без нужного расширения в имени.
- Результат работы команд можно выводить в файл с помощью `>`.

### 🛠️ Команды

| Команда              | Что делает                                                                        |
| -------------------- | --------------------------------------------------------------------------------- |
| mkdir dnam           | создает папку                                                                     |
| touch fnam           | создает файл                                                                      |
| cp fnam              | копирует файл нужно указать путь куда копировать                                  |
| mv fnam dnam1/dnam2  | премещяет файл                                                                    |
| mv fnam1 fnam2       | переименует файлы                                                                 |
| file                 | определяет тип файла и способ его сжатия                                          |
| gzip -d fnam.gz      | распаковать gzip-файл                                                             |
| bzip2 -d fnam.bz2    | распаковать bzip2-файл                                                            |
| xxd -r fnam1 > fnam2 | перевод из hex-дампа обратно в текст `>` переводит вывод команды в отдельный файл |
| tar -xf fnam2.tar    | распаковать tar-архив                                                             |
