### 🎯 Что делал

Уже на 8 уровне я научился связывать команды с помощью пайпа `|`. Он переводит вывод из левой команды в правую, а потом уже в терминал. Например, мне надо было найти в файле нужную неповторяющуюся строку из сотни повторяющихся. Для этого мне нужна была команда `uniq`. Сама по себе она убирает повторяющиеся строки, но с флагом `-u` она показывает строки, которые не повторяются. Однако `uniq` убирает только соседние дубликаты, и надо сначала отсортировать строки командой `sort`. Для этого мне и понадобился `|`, который перевёл вывод команды `sort` в команду `uniq`, а не в терминал. Полная команда: `sort data.txt | uniq -u`, после чего мне и вывелся нужный пароль.

---
### 🧠 Что понял

- Некоторые команды не могут дать нужный результат сами по себе, но их можно связать с другими командами с помощью `|`.
- Команда `uniq` без сортировки мало чем полезна.
- При работе с `|` не надо писать имя файла после каждого пайпа — достаточно одного раза, в начале, в первой команде.

---
### 🛠️ Команды

| Команда              | Что делает                                                                                                          |
| -------------------- | ------------------------------------------------------------------------------------------------------------------- |
| sort                 | сортирует строки файла по алфавиту                                                                                  |
| uniq                 | убирает соседние дублирующиеся строки                                                                               |
| uniq -u              | показать только строки встречающиеся  один раз                                                                      |
| sort fnam \| uniq -u | выполняет обе команды, но `\|` передаёт вывод левой команды на вход правой  —  она читает то, что пришло через пайп |
