### 🎯 Что делал

Я уже на 5 уровне Bandit и научился пользоваться командой `find`. Задача была среди множества разных папок и файлов найти файл с паролем по трём определённым критериям. Одним из них был размер файла — 1033 байта, и по этому критерию командой
`find . -size 1033c` я нашёл нужный мне пароль.

---
### 🧠 Что понял

- Искать среди множества файлов один определённый вручную — долго и утомительно. 
- Зная параметры файла, легче найти нужный с помощью команды `find`

---
### 🛠️ Команды

| Команда                       | Что делает                                               |
| ----------------------------- | -------------------------------------------------------- |
| find . -name                  | ищет файл по имени (. - это текущая папка поиска)        |
| find . -size 1033с            | ищет файл по размеру например 1033с (с - означает байты) |
| find . -name fnam -size 1033c | комбинация критериев поиска                              |
